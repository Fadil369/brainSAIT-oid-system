# BrainSAIT OID FHIR Integration Platform
## IANA PEN 61026 — FHIR R4/R5 OID Integration Toolkit

Complete toolkit for integrating BrainSAIT OID namespaces into FHIR-based
healthcare systems, including IG templates, FSH libraries, and migration tools.

## Contents

- `toolkit/` — Core FHIR integration utilities
- `ig-template/` — Implementation Guide template with OID binding
- `fsh-library/` — FHIR Shorthand (FSH) library for OID extensions
- `migration/` — StructureDefinition OID migration tools

## FHIR OID Integration

```json
{
  "system": "urn:ietf:rfc:3986",
  "value": "urn:oid:1.3.6.1.4.1.61026.3.2"
}
```
