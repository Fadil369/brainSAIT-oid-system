# BrainSAIT OID Healthcare AI Identity Suite
## IANA PEN 61026 — Healthcare Identity & Interoperability

The Healthcare AI Identity Suite delivers a comprehensive OID-based identity
infrastructure for healthcare organizations, covering FHIR R4/R5, NPHIES,
DICOM, SNOMED CT, and HL7 v2/v3 integration.

## Suite Contents

- `fhir-ext/` — FHIR extension definitions with OID anchoring
- `audit-schema/` — HIPAA-compliant audit trail schemas
- `snomed-ct-oid-mapping.json` — SNOMED CT to OID mappings
- DICOM UID allocation block documentation
- HIPAA namespace documentation
