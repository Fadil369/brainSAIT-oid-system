# BrainSAIT OID White-Label Reseller Guide

## Getting Started

1. **Request your tenant namespace** — Contact enterprise@brainsait.com
2. **Configure branding** — Update `brand-kit/brand-config.json` with your brand
3. **Deploy the portal** — Use the provided Docker Compose or Kubernetes manifests
4. **Onboard customers** — Use the Admin API to create sub-namespaces

## Tenant Namespace Structure

```
1.3.6.1.4.1.61026.9.<tenant-id>     — Your dedicated namespace
1.3.6.1.4.1.61026.9.<tenant-id>.1   — Your customers' namespaces
```
