# BrainSAIT OID White-Label Enterprise Package
## IANA PEN 61026 — White-Label OID Platform

Complete white-label package for deploying a branded OID management platform
under your organization's identity, powered by BrainSAIT's IANA PEN 61026 infrastructure.

## Package Contents

- `portal-source/` — React-based OID portal source code
- `brand-kit/` — Branding assets and customization guides
- `reseller-guide.md` — Reseller setup and configuration guide

## Multi-Tenant Architecture

Each tenant receives a dedicated sub-namespace under IANA PEN 61026, ensuring
globally unique OID assignments with full white-label branding.
